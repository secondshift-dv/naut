## Tu colección, hecha para explorarla.

Naut es un **gestor de colecciones multimedia local-first para Windows**. Convierte imágenes, vídeos y modelos 3D compatibles en colecciones centradas en Profiles que se pueden reconocer, presentar y explorar sin entregar el control a un servicio en la nube.

## Optional pack collection

Make Naut yours with reviewed, independently versioned customization packs.
Download a pack, import it in **Settings → Presentation → Packs / Advanced**,
then choose its components and save. Application code stays unchanged.

**[Browse and download packs](packs/README.md) · [Install or update a pack](docs/pack-collection.md) · [Contribute your own](docs/contributing-packs.md)**

## Por qué Naut

- **Profiles antes que carpetas.** Un Profile puede representar una persona, personaje, proyecto, objeto, tema o cualquier identidad de colección.
- **Control local por diseño.** La colección autoritativa vive en el Vault que eliges.
- **Preparado para explorar.** Naut crea derivados de presentación limitados sin modificar los originales.
- **3D es adicional, no obligatorio.** El uso normal no requiere una GPU dedicada ni una Figure.
- **Aplicación portátil, colección duradera.** Actualizar la aplicación no reemplaza el Vault.

## Inicio rápido

1. Descarga **Naut v0.0.3** desde el [GitHub Release](https://github.com/secondshift-dv/naut/releases/tag/v0.0.3) oficial.
2. Extrae el ZIP completo en una carpeta normal.
3. Ejecuta `naut.exe`.
4. Elige dónde guardar el Vault.
5. Importa medios o crea un Profile y usa **Add media**.

`runtime/` y `release-manifest.json` deben permanecer junto a `naut.exe`. Para una vista previa en navegador sin tocar archivos locales ni Vault: [Interactive Showcase](https://secondshift-dv.github.io/naut/).

## Requisitos del sistema

La experiencia normal de Naut es deliberadamente más ligera que la carga opcional de Figures.

| | Minimum | Recommended |
| --- | --- | --- |
| **SO** | Windows 10/11 64-bit | Windows 11 64-bit |
| **CPU** | x86-64, 2 núcleos | x86-64 moderno, 4+ núcleos |
| **RAM** | 8 GB | 16 GB |
| **GPU** | Gráficos integrados para uso normal | GPU integrada/dedicada compatible con Direct3D 11 para Figures más fluidas |
| **Pantalla** | 1280 × 720 | 1920 × 1080 o superior |
| **Espacio app/update** | 1.5 GB | 1.5 GB+ en SSD |

El almacenamiento del Vault es independiente y depende de la colección. Consulta [Naut v0.0.3 System Requirements](docs/system-requirements.md).
