Naut は Windows 向けの **ローカルファーストなメディアコレクション管理アプリ**です。Profile を中心に画像、動画、任意のインタラクティブ 3D Figure をポータブルな Vault にまとめます。

インポートはファイルを Vault にコピーし、元ファイルを残します。Cover、Banner、レイアウト、Frame、Backdrop、Effect、Theme は元メディアを置き換えずに変更できます。Figure は Direct3D 11 を使う任意のワークロードで、通常の Naut 利用にディスクリート GPU は必須ではありません。

**GitHub Releases** から ZIP をダウンロードして完全に展開し、`naut.exe` を起動して Vault フォルダーを選択してください。[ドキュメント](docs/README.md) と [システム要件](docs/system-requirements.md) も参照してください。

Naut 独自ソースは PolyForm Shield 1.0.0 に基づく **Source Available** です。公式バイナリと署名済み更新メタデータは `secondshift-dv/naut` の公式 **GitHub Releases** からのみ配布されます。
