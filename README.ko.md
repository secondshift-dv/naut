Naut는 Windows용 **로컬 우선 미디어 컬렉션 관리자**입니다. Profile을 중심으로 이미지, 비디오, 선택적 인터랙티브 3D Figure를 휴대 가능한 Vault에 정리합니다.

가져오기는 파일을 Vault에 복사하며 원본을 유지합니다. Cover, Banner, 레이아웃, Frame, Backdrop, Effect, Theme은 원본 미디어를 바꾸지 않고 조정할 수 있습니다. Figure는 Direct3D 11 기반의 선택적 워크로드이며 일반적인 Naut 사용에는 고성능 외장 GPU가 필요하지 않습니다.

**GitHub Releases**에서 ZIP을 다운로드해 완전히 압축 해제한 뒤 `naut.exe`를 실행하고 Vault 폴더를 선택하세요. [문서](docs/README.md)와 [시스템 요구 사항](docs/system-requirements.md)을 참고하세요.

Naut 소유 소스는 PolyForm Shield 1.0.0에 따른 **Source Available**입니다. 공식 바이너리와 서명된 업데이트 메타데이터는 `secondshift-dv/naut` 공식 **GitHub Releases**를 통해서만 배포됩니다.
