# Security

Report suspected vulnerabilities privately through this repository's Security reporting surface. Do not disclose exploit details, tokens, signing keys or private Vault data in public issues.

Official binaries and signed update metadata come only from https://github.com/secondshift-dv/naut/releases. A hash establishes file integrity; verify the official release origin as well.

Contributions must preserve Vault, persistence, updater and package trust boundaries. Public pull requests receive read-only checks and never receive release signing credentials.
