Naut est un **gestionnaire multimédia local-first pour Windows**. Les Profiles regroupent images, vidéos et Figures 3D interactives facultatives dans un Vault portable.

L'importation copie les fichiers dans le Vault et conserve les originaux. Cover, Banner, dispositions, Frames, Backdrops, effets et thèmes peuvent changer sans remplacer le média original. La Figure interactive utilise Direct3D 11 comme charge facultative ; un GPU dédié n'est pas requis pour l'utilisation normale.

Téléchargez le ZIP depuis **GitHub Releases**, extrayez-le entièrement, lancez `naut.exe` et choisissez le dossier du Vault. Voir la [Documentation](docs/README.md) et la page [Configuration requise](docs/system-requirements.md).

Le code appartenant à Naut est **Source Available** sous PolyForm Shield 1.0.0. Les binaires officiels et métadonnées de mise à jour signées sont distribués uniquement via les **GitHub Releases** officiels de `secondshift-dv/naut`.
