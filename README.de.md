## Eine Sammlung, die es wert ist, erkundet zu werden.

Naut ist ein **local-first Medien-Sammlungsmanager für Windows**. Bilder, Videos und unterstützte 3D-Modelle werden zu Profile-zentrierten Sammlungen, die sich erkennen, präsentieren und erkunden lassen, ohne die Kontrolle an einen Cloud-Dienst abzugeben.

## Warum Naut

- **Profiles statt Ordner zuerst.** Ein Profile kann Person, Figur, Projekt, Objekt, Thema oder eine andere Sammlungsidentität darstellen.
- **Lokale Kontrolle.** Die maßgebliche Sammlung liegt im gewählten Vault.
- **Für schnelles Browsing vorbereitet.** Naut erzeugt begrenzte Präsentationsderivate statt Originale zu verändern.
- **3D ist optional.** Normale Nutzung erfordert weder eine diskrete GPU noch eine Figure.
- **Portable Anwendung, dauerhafte Sammlung.** Ein App-Update ersetzt den Vault nicht.

## Schnellstart

1. **Naut v0.0.3** aus dem offiziellen [GitHub Release](https://github.com/secondshift-dv/naut/releases/tag/v0.0.3) herunterladen.
2. Das vollständige ZIP in einen normalen Ordner entpacken.
3. `naut.exe` starten.
4. Den Speicherort für den Vault wählen.
5. Medien importieren oder ein Profile erstellen und **Add media** verwenden.

`runtime/` und `release-manifest.json` müssen neben `naut.exe` bleiben. Für eine Browser-Vorschau ohne Zugriff auf lokale Dateien oder Vault: [Interactive Showcase](https://secondshift-dv.github.io/naut/).

## Systemanforderungen

Die normale Naut-Nutzung ist bewusst leichter als die optionale Figure-Arbeitslast.

| | Minimum | Recommended |
| --- | --- | --- |
| **OS** | Windows 10/11 64-Bit | Windows 11 64-Bit |
| **CPU** | x86-64, 2 Kerne | Moderner x86-64, 4+ Kerne |
| **RAM** | 8 GB | 16 GB |
| **GPU** | Integrierte Grafik für normale Nutzung | Direct3D-11-fähige integrierte/diskrete GPU für flüssigere Figures |
| **Display** | 1280 × 720 | 1920 × 1080 oder höher |
| **Freier App-/Update-Speicher** | 1,5 GB | 1,5 GB+ auf SSD |

Vault-Speicher ist separat und hängt von der Sammlung ab. Siehe [Naut v0.0.3 System Requirements](docs/system-requirements.md).
