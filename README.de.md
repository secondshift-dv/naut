Naut ist ein **lokaler Medienmanager für Windows**. Profile organisieren Bilder, Videos und optionale interaktive 3D-Figuren in einem portablen Vault.

Import kopiert Dateien in den Vault; die Originale bleiben bestehen. Darstellung, Cover, Banner, Layouts, Frames, Backdrops, Effekte und Themes können geändert werden, ohne die Originalmedien zu ersetzen. Interactive Figure ist eine optionale Direct3D-11-Arbeitslast und kein Grundbedarf für Naut.

Start: ZIP von **GitHub Releases** laden, vollständig entpacken, `naut.exe` starten und einen Vault-Ordner auswählen. Siehe [Dokumentation](docs/README.md) und [Systemanforderungen](docs/system-requirements.md).

Naut-eigener Quellcode ist **Source Available** unter PolyForm Shield 1.0.0. Offizielle Binärdateien und signierte Update-Metadaten werden ausschließlich über die offiziellen **GitHub Releases** von `secondshift-dv/naut` verteilt.
