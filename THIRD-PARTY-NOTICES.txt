Third-Party Runtime Notices — Source Reference

This file describes the source-side compliance authority; it is not a release-specific
inventory of runtime binaries. Each official Naut package contains its authoritative,
versioned runtime/THIRD-PARTY-NOTICES.txt and runtime/LICENSES/ directory.

The notices in the package are generated from the exact resolved artifacts during
the canonical build. They identify bundled models, libraries, fonts, licenses,
source revisions, checksums, and corresponding-source archives. The build verifies
those artifacts and their license inventory before producing a release ZIP.

Source authorities:
- scripts/packaging/package-win-x64.ps1 — runtime notices generator.
- scripts/packaging/runtime-third-party.lock.json — native runtime and licenses.
- scripts/packaging/ffmpeg/ffmpeg-runtime.lock.json — FFmpeg build and sources.
- src/Neuterradise.App/Assets/Presentation/BuiltIn/Fonts/provenance.json — fonts.
- release-contract.json — required packaged notice and runtime members.

For notices applicable to an installed or downloaded Naut version, use the copy
inside that version's official distribution. Historical release packages retain
their own generated notices; this source reference intentionally has no product
version or frozen runtime hashes.
