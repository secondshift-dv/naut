# Languages

Naut v0.0.2 ships with **eight interface languages**:

- English
- Bahasa Indonesia
- 日本語
- 한국어
- 简体中文
- Deutsch
- Français
- Español

English is the default/fallback language.

## Changing the interface language

Use **Settings** to choose the Naut interface language. Language selection changes application surface text; it is not a migration of the Vault.

Changing the interface language does **not** rewrite:

- Profile names;
- categories or tags;
- private notes;
- filenames or original media;
- media metadata stored as collection data;
- the Vault folder name.

This keeps presentation language separate from the user's collection content.

## README translations are separate

The language links at the top of the GitHub README select a translated README. They are separate from the eight languages available inside the Naut application.

For appearance and presentation choices that sit alongside language in Settings, see [Customization](customization.md).
