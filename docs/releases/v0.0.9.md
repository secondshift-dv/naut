# Naut v0.0.9

## Highlights

- Profile Banner Collection keeps ordered alternatives across restart and Vault moves. Add as Banner prepares another video without replacing the active choice; Save/Cancel controls selection, framing and effects.
- New video HOVER uses 480p at 24 FPS; selected Banner renditions use up to 900p at 24 FPS. Small originals reuse one rendition, and existing ready HOVER files are preserved.
- New-Profile imports prepare up to three initial Banner alternatives with candidate fallback. Existing-Profile imports keep the saved collection and appearance.
- Film, Glitter and Shimmer compose at display time, with per-Profile intensity and no re-encoding.
- Background transfers use measured foreground I/O and dispatcher responsiveness to select 0/2/4 ms yields per 4 MiB while preserving SHA-256 and durable checkpoints.

## Download and update

Download [Naut v0.0.9 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.9/naut-v0.0.9-win-x64.zip). For a new installation, extract the complete ZIP to a normal folder and run `naut.exe`; keep the bundled `runtime/` directory and release metadata alongside it. Do not run the EXE directly from the ZIP.

Existing installations can use Naut's authenticated updater. Keep a backup of the entire Vault before upgrading because the new Catalog schema is not writable by older versions.

## Notes

Catalog v1/v2 upgrades preserve media identities and selections while advancing to schema v3. Profile manifests write schema 2 and continue reading schema 1. Older binaries cannot write an upgraded Catalog; downgrade requires a pre-upgrade Vault backup.

Legacy active HOVER references remain preserved. High-resolution sources use a static Thumbnail until a dedicated Banner is explicitly added; missing/corrupt Banner files preserve repairable membership and use a still fallback. Original bytes, Vault identity and updater boundaries remain unchanged.

The release was verified through automated build/source checks, Catalog migration and rollback, disposable-Vault lifecycle and media/presentation diagnostics. Long-duration runtime testing, manual performance benchmarks and visual acceptance were not performed. No measured performance gain or visual acceptance is claimed.
