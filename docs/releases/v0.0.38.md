# Naut v0.0.38

## Highlights

- Duplicate-heavy imports now perform scoped preparation and skipped-media settlement, reducing unnecessary database work when existing media already belongs to the selected Profile.
- Import activity and Review avoid redundant refreshes and dispatcher work while preserving cancellation, prioritization, publication and duplicate accounting.
- Profile navigation reuses media-card metadata controls and cached resources. Foreground image decoding reduces temporary managed allocations; Figure rendering retains bounded scene reuse and releases viewport resources.
- Application replacement and startup recovery use stronger operation isolation, backup identity checks and path validation. Vault data and AppState remain separate from the installation.
- See [measured performance](../performance.md) for synthetic development benchmarks and their limitations.

## Download and update

Download the [Windows x64 ZIP](https://github.com/secondshift-dv/naut/releases/download/v0.0.38/naut-v0.0.38-win-x64.zip) from GitHub Releases. New users extract the complete archive and launch naut.exe. Existing users can check for the signed update from Settings.

## Notes

Catalog schema remains 3; this release does not introduce a schema migration. No additional SSD cache or dependency upgrade is required. Benchmark results describe isolated development workloads, not guaranteed production or release-package throughput.
