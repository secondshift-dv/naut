# Naut v0.0.34

## Highlights

- Release icons and card overlays when Customize discards a preview. Defer backdrop image work until the view loads and reuse cached pack images across previews.
- Read image metadata from one source buffer during import, avoiding extra full-file copies while keeping the existing metadata readers.
- Keep a matching Profile Banner playing while Customize rebuilds the preview. Use a small reusable buffer for normal video frames and release mask resources when the artwork leaves the view.
- Stop frame animation callbacks when visual rendering is suspended or uses the static fallback.

## Download and update

Download [Naut v0.0.34 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.34/naut-v0.0.34-win-x64.zip). Extract the complete archive and run Naut. Existing users can update through **Settings → About**.

## Notes

This update requires no Vault migration. Existing media and presentation choices remain available after updating.
