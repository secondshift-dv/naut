# Naut v0.0.6

A presentation update for cleaner cards and correctly separated Cover/Banner identity.

## Highlights

- **Banner stills come from the selected video.** Gallery cards and Home spotlight resolve the thumbnail paired with the selected prepared Banner video, independently of Cover. Hover playback continues to use that Banner video.
- **Smaller Card Customize action.** A 24-pixel icon replaces the large gold control on cards, preserving the tooltip and accessible name while covering less artwork.
- **Explicit image fallback for packs.** Card image nodes can request `fallback: none` to keep an unavailable Banner empty. Existing packs retain their default identity fallback.
- **BLACK DOSSIER 1.0.0** is available as an optional, separate eleven-component pack: neutral black, restrained crimson, original architectural backdrop, bundled typography and a gunmetal Cover frame. Its Profile keeps the Banner and native Figure, with Delete at the bottom.

## Download and update

[Download Naut v0.0.6 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.6/naut-v0.0.6-win-x64.zip).

New users: extract the ZIP and run `naut.exe`. Existing users: update through Naut or manually replace the application files using this ZIP. Keep your Vault separate from the application folder.

[Download BLACK DOSSIER 1.0.0](https://secondshift-dv.github.io/naut/packs/black-dossier-1.0.0.ntpack). Install the pack from Settings > Presentation, then select its components and save changes. Pack installation does not select them automatically.

## Notes

- BLACK DOSSIER requires Naut 0.0.6 or later for its separate Banner still and no-Cover-fallback policy. Use Square Covers for Gunmetal Seal.
- Missing Banner thumbnails remain empty in that card; this update does not generate media during browsing. Hover respects scrolling, playback and resource policies.
- Signal Trace must be selected independently for Home, Profile and Card. Reduced Motion uses its static fallback; offscreen effects pause.
- Signed update manifests, staging, backups, rollback and Vault isolation remain enforced. Figures remain static models; FBX, OBJ, STL and 3MF conversion requires Microsoft Visual C++ v14 Redistributable x64.
