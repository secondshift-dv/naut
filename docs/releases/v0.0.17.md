# Naut v0.0.17

## Highlights

- **Delete individual presentation files where they belong.** Fonts, transparent Frames and Backdrops imported directly as files now have a Delete action on their respective Settings → Presentation library cards. Files in use revert their presentation bindings to built-in defaults without deleting Profiles or media.
- **Separate direct files from contractual packs.** The library marks direct file imports separately from items managed by .ntpack, ZIP or folder packs. Contractual packs remain removable only through Packs / Advanced, and built-in definitions remain protected.
- **Reversible deletion in Media Inspector.** Each active media item now exposes a confirmed Delete action that uses the existing recoverable Trash operation. The Vault coordinator preserves the media record and Face data, detaches Profile relations and Cover/Banner/Figure selections, and allows restoration through Settings → Trash Bin.

## Download and update

Download [Naut v0.0.17 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.17/naut-v0.0.17-win-x64.zip). Extract the complete archive and run `naut.exe` alongside the supplied `runtime/` and `release-manifest.json`. Existing users can update through the signed in-app updater when available.

The updater replaces application files only. Existing Vault contents, original media, Profile data, derivatives, and preferences remain outside the update payload.

## Notes

- Existing presentation installations without a recorded individual-file intake source remain managed through Packs / Advanced; reinstall the original font or artwork directly to use per-file Delete.
- Media moved to Trash can be restored within the 30-day retention window. Permanent purge remains a separate Trash action.
- No Vault or database schema migration, original-media conversion, updater-security change, or release-layout change.
