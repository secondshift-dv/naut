# Naut v0.0.24

## Highlights

- Rejected faces no longer influence automatic Profile assignment. Import checks that strong suggestions still match the current identity bank before using them.
- Figure camera and Inspector image preferences retry temporary catalog write failures. Shutdown waits for the admitted writes to finish.
- Home, Gallery, and Settings discard older results when a newer refresh has started, keeping the current view consistent.

## Download and update

Download [Naut v0.0.24 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.24/naut-v0.0.24-win-x64.zip). For a new installation, extract the complete archive and run `naut.exe`. Existing users can update through Settings → About.

## Notes

Confirmed face decisions and existing Vaults remain compatible. This release adds no schema migration or system requirements.
