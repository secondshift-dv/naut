# Naut v0.0.28

## Highlights

- Use **Customize Home → Layout → Show Recently** to hide the activity section. Continue keeps its own place in the layout.
- Presentation packs can arrange Home and Profile modules in responsive grids and overlays. Profile layouts can place Figure 3D in its own region.
- Pack artwork can use PNG alpha masks and independent rotations on Spotlight and Profile Banner. Compatible installed effects appear in the Banner effect picker.
- Figure 3D uses 2× multisample antialiasing when supported. New model derivatives preserve color at transparent texture edges. Vault Health can queue a refresh for affected older derivatives.

## Download and update

Download [Naut v0.0.28 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.28/naut-v0.0.28-win-x64.zip). Extract the complete archive and run `naut.exe`. Existing users can update through Settings → About.

## Notes

Presentation Contract 1 packs and existing Vaults remain readable. Packs that use the new layout or artwork options require Presentation Contract 2.
