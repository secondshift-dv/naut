# Naut v0.0.16

## Highlights

- **Video import recovery.** Videos whose duration or face-analysis timestamp extends beyond the last decodable frame no longer fail just because Naut sought too far for a thumbnail. Naut keeps thumbnail selection away from the container tail and retries from the beginning if the requested frame is unavailable.
- **Keep valid video previews.** When a thumbnail must be retried, Naut reuses valid Hover and Banner renditions produced by the first encoding pass instead of unnecessarily re-encoding them.
- **Actionable import failures.** The Import review now shows the safe underlying preparation error and capability/error code, rather than only a generic message, when a required media asset still cannot be prepared.

## Download and update

Download [Naut v0.0.16 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.16/naut-v0.0.16-win-x64.zip). Extract the complete archive and run `naut.exe` alongside the supplied `runtime/` and `release-manifest.json`. Existing users can update through the signed in-app updater when available.

The updater replaces application files only. Existing Vault contents, original media, Profile data, derivatives, and preferences remain outside the update payload.

## Notes

- No Vault or database schema changes, packaging contract changes, signing-key rotation, or original-media conversion.
- Video streams with no decodable frames or incompatible media properties can still require Import review or cancellation.
