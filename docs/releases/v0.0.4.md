# Naut v0.0.4

This release fixes imports that stayed on Preparing media and expands the formats you can use as interactive 3D Figures.

## Highlights

- **MPG and MPEG imports can reach review.** Files whose preparation had finished could remain stuck on Preparing media. Naut now recognizes completion at the correct import stage.
- **More formats for Profile Figures.** Use FBX, OBJ, STL, GLB, or 3MF models as Figures, with rotation, pan, and zoom.
- **Unicode model filenames work.** Model preparation preserves names containing characters such as Japanese text, including supported OBJ material and texture dependencies.

## Download and update

[Download Naut v0.0.4 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.4/naut-v0.0.4-win-x64.zip).

New users: extract the ZIP and run `naut.exe`. See the [getting started guide](https://github.com/secondshift-dv/naut/blob/v0.0.4/docs/getting-started.md).

Existing users: use Naut's updater, or close Naut and replace the application files with the extracted package. Keep your Vault separate from the application folder; application updates do not modify the Vault.

## Notes

- FBX, OBJ, STL, and 3MF conversion requires [Microsoft Visual C++ v14 Redistributable x64](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist/).
- Figures display static models. Model animation and rig playback are not supported.
- Supported OBJ material and PNG/JPEG texture files must be included with the model. Unsupported or missing dependencies may prevent Figure preparation.
