# Naut v0.0.35

## Highlights

- Naut reads image headers and embedded metadata without copying the entire image into memory. This reduces memory use during import, especially for large images.
- Cancelling an import now shows its cancellation status and hides actions that no longer apply. If cleanup still needs attention, the import shows that separately.

## Download and update

Download [Naut v0.0.35 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.35/naut-v0.0.35-win-x64.zip). Extract the complete archive and run Naut. Existing users can update through **Settings → About**.

## Notes

This update requires no Vault migration.
