# Naut v0.0.23

## Highlights

- Import avoids repeating completed work during preparation. Naut schedules preparation for each copied file without scanning the whole batch and validates finished thumbnails and previews when the batch is ready for review.
- Catalog reads for Home, Gallery, and Settings run off the interface thread, reducing competition with navigation during imports.
- Face suggestions require a higher similarity score and a clear lead over other matches. Previous suggestions are checked when shown. Import applies a higher bar for acting on a match, and video analysis groups face detections more conservatively.

## Download and update

Download [Naut v0.0.23 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.23/naut-v0.0.23-win-x64.zip). For a new installation, extract the complete archive and run `naut.exe`. Existing users can update through Settings → About.

## Notes

The face policy favors leaving uncertain detections unassigned, so some valid matches may require manual review. Existing confirmed identities and the Vault schema are preserved.
