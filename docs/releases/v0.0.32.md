# Naut v0.0.32

## Highlights

- Select an installed pack inside Customize Home to preview its available Layout, Spotlight, Backdrop and Effect together.
- Select a pack in Customize Profile to preview its available page and media layouts, frame, backdrop and effects, plus the Profile's Card design. Individual choices remain editable until Save Changes.
- Settings → Presentation opens on Packs / Advanced, with installation and pack management available immediately.

## Download and update

Download [Naut v0.0.32 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.32/naut-v0.0.32-win-x64.zip). Extract the complete archive and run Naut. Existing users can update through **Settings → About**.

## Notes

This release has no additional prerequisites. Previously installed compatible packs can be used with the new picker. Each pack fills the slots it provides for the current editor.
