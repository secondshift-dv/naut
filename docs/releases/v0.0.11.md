# Naut v0.0.11

## Highlights

- Fixed video Banners that could remain frozen after reopening Customize or reflowing the Profile header. The selected ready Banner now resumes when its host is loaded again.
- Fixed first-open Figure 3D readiness when Profile layout changes briefly detach the native viewport while the scene is still loading.
- Home Spotlight now reevaluates ready video playback on activation and Resource Governor changes rather than requiring navigation to restart it.
- An active Import now reduces decorative effects and Figure texture detail without automatically suspending ready Home Spotlight and Profile Banner video. Memory pressure, reduced-motion settings, and inactive or minimized windows still suppress primary video.
- Foreground Figure scene requests now take priority over queued CPU background work. Optional Figure prewarming yields to interaction, Import, and memory pressure while retaining original NFIG integrity validation.

## Download and update

Download [Naut v0.0.11 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.11/naut-v0.0.11-win-x64.zip). Extract the complete ZIP into a normal application folder and run naut.exe with its bundled runtime/ directory and release metadata intact. Do not run the EXE directly from the ZIP.

Existing users can use Naut's authenticated updater. Vault data stays separate from the installation and does not require reimporting.

## Notes

No Catalog schema or signed-updater contract changes are introduced. The existing 0.0.10 Vault and user customization remain compatible.

The fixes have automated source and focused isolated verification, but no claim is made for manual visual acceptance, real-HDD speed improvement, or long-duration runtime testing.
