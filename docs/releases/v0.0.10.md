# Naut v0.0.10

## Highlights

- First-run Vault selection now warns that Vault data must live outside the Naut installation and AppData folders. If a selected folder overlaps either location, Naut explains the conflict and suggests choosing a separate sibling folder instead of showing a generic opening failure.
- The first-run folder picker opens in a compact, centered window (up to 700 × 540 device-independent pixels). When the Vault opens, the main application returns to its normal saved or monitor-appropriate window size.
- The built-in presentation defaults now use Logbook Theme, Dashboard Home, Cinematic Spotlight, Pinboard Gallery, Portrait Profile and Mosaic Media. Editorial Card remains the default; saved custom selections remain in effect.
- About now reads published-release dates from GitHub even when the release has a large list of assets. Previously a valid response larger than 256 KiB appeared as "Release date unavailable"; network failures still leave the date unavailable rather than inventing a date.

## Download and update

Download [Naut v0.0.10 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.10/naut-v0.0.10-win-x64.zip). Extract the complete ZIP into a regular application folder and run `naut.exe`, keeping the bundled `runtime/` directory and release metadata with it. Do not run the EXE directly from the ZIP.

Existing installations can update through Naut's authenticated updater. Keep the Vault in a separate directory from the application; no Vault data needs to be moved or reimported for this release.

## Notes

This release does not change the Vault Catalog schema or the signed-update security model. Existing Vaults and stored presentation customization remain supported. Built-in fallback appearance changes may also apply to older Vaults where a selection was never explicitly saved.

Automated contract checks cover the new folder-location rejection and neutral preset defaults. Manual visual acceptance and long-duration operation are not claimed.
