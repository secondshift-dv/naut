# Naut v0.0.41

## Highlights

- Immersive Home Spotlight supports configurable marquee angle, spacing, text color and metadata visibility. Cover-only Favorites rails support scaled covers and an optional bounded, looping reel with manual navigation and resource-aware pausing.
- Custom navigation can be switched to native navigation from a compact, consistently positioned breadcrumb control.
- Contract 4 scenes support local native button colors and states, border and typography overrides. Independent Profile Banner regions support larger authored dimensions and responsive aspect ratios.
- Profile layouts support bounded, independent vector icon styles for section headings, rating and Favorite; media layouts support Open, Info and Favorite icon overrides. Section headings also support local text color and size.
- Paper-style Profiles can retain their selected backdrop behind translucent panels, and Profile Cards can declare text outlines for resting and Banner-hover compositions.
- Replacing installed presentation artwork invalidates affected image-cache entries and updates media artwork identity without clearing unrelated cached images.

## Download and update

Download the [Windows x64 ZIP](https://github.com/secondshift-dv/naut/releases/download/v0.0.41/naut-v0.0.41-win-x64.zip) from GitHub Releases. New users extract the complete archive and launch naut.exe. Existing users can check for the signed update from Settings.

## Notes

Presentation Contract 4 and Catalog Schema 4 remain unchanged. New optional fields require this renderer; omission retains existing behavior. Banner geometry remains bounded by the allocated scene and viewport. Application replacement remains separate from Vault storage. Users upgrading from a pre-schema-4 release should back up the complete Vault before opening it. No new performance benchmark or visual acceptance result is claimed.
