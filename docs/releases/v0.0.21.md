# Naut v0.0.21

## Highlights

- Profile Figures remember rotation, pan, and zoom when you reopen a Profile or restart Naut. Each Profile keeps its own camera for each model. Use **Reset view** to restore and save the default position.
- The image Inspector remembers zoom, Fit, and Actual size for each image in its Profile.

## Download and update

Download [Naut v0.0.21 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.21/naut-v0.0.21-win-x64.zip). For a new installation, extract the complete archive and run `naut.exe`. Existing users can update through Settings → About.

## Notes

This release adds no system requirements or catalog migration. Existing Vaults start with the default view until you adjust it.
