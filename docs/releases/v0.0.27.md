# Naut v0.0.27

## Highlights

- Profile names support emoji, including composed sequences. When a rename is rejected, the editor keeps your changes and shows the reason. Vault filenames reconcile in the background.
- Reopened imports return to the saved step. If the destination is missing or unavailable and placement has yet to lock it, choose a Profile before continuing to Review.
- Media Grid, Inspector, and the Profile media pickers show the current Vault filename. Inspector also shows the source filename. Profile renames can update the capitalization of managed files and 3D package folders.
- Figure 3D uses offline studio lighting and reflections. Open Controls below the viewport for gesture help, or use Reset view on the same row.

## Download and update

Download [Naut v0.0.27 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.27/naut-v0.0.27-win-x64.zip). Extract the complete archive and run `naut.exe`. Existing users can update through Settings → About.
