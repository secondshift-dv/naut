# Naut v0.0.25

## Highlights

- Managed images, videos, and models now use single underscores between the Profile name, media type, and short ID. For example, `Anas__video__a1b2c3d4.mp4` becomes `Anas_video_a1b2c3d4.mp4`.
- Models with dependencies use the new naming pattern for the package folder. The model and its dependencies keep their names and relative paths inside the folder.
- Naut updates existing managed originals in place and keeps your Cover, Banner, and Figure 3D selections. Items in Trash use the new naming pattern when restored.

## Download and update

Download [Naut v0.0.25 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.25/naut-v0.0.25-win-x64.zip). Extract the complete archive and run `naut.exe`. Existing users can update through Settings → About.

## Notes

The first time you open an existing Vault, Naut shows progress while it updates managed media names. This can take longer for large collections. Media source files outside the Vault stay in place.
