# Naut v0.0.42

## Highlights

- Profile Relation and Order controls adapt their text and arrow contrast to the local control background. Paper-style Profile layouts can override individual semantic colors, including secondary, muted and disabled text, independently of the global theme.
- Home viewport stages retain their authored scene geometry while the backdrop extends across the viewport. Modular Profile layouts offer an opt-in Maintain composition setting.
- Settings includes independent Navigator, Breadcrumb and Navigator switch visibility, persistent Native/Custom navigation mode, and native-window keyboard recovery, including Ctrl + , for direct Settings access. Custom navigation can overlay Home, Gallery and Profile independently.
- Gallery has an independent surface effect picker. Banner customization uses numbered slots, slot-aware artwork previews, and separate media and scene effect controls.
- The backdrop renderer coordinates native resource retirement with rendering and clears paint references before disposing temporary shaders and filters.
- The minimum supported outer window is 800 × 500 DIP. Compact and standard visual acceptance target 800 × 500 and 1366 × 768.

## Download and update

The [Windows x64 ZIP](https://github.com/secondshift-dv/naut/releases/download/v0.0.42/naut-v0.0.42-win-x64.zip) is available from GitHub Releases. New users extract the complete archive and launch naut.exe. Existing users can check for the signed update from Settings.

## Notes

Presentation Contract 4 and Catalog Schema 4 remain unchanged. Maintain composition defaults off for compatibility with existing modular layouts. No crash-free runtime or visual acceptance result is claimed by the source changes alone. Application replacement remains separate from Vault storage. Users upgrading from a pre-schema-4 release should back up the complete Vault before opening it.
