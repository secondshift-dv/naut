# Naut v0.0.15

## Highlights

- **Clearly selected Banner Effects.** None, Film, Glitter, and Shimmer now show the active selection in the Banner editor. Previously, every option looked identical.
- **More visible Banner effects.** Film grain and edge shade, scattered Glitter stars, and a moving Shimmer highlight use a more readable intensity curve and refined rendering. Zero intensity still disables the overlay; reduced-motion and fallback display static treatments.
- **Bubbles replace Aurora on Home and Profile.** Floating outline bubbles replace Aurora's barely visible glow. Previously selected Aurora definitions resolve to Bubbles without changing the Vault or user media.
- **Readable Gallery search.** The compact search field uses a concise placeholder; its full Profile/category/tag search hint remains available in the tooltip. The field no longer requires a long placeholder to fit inside a narrow toolbar.
- **Optional pack documentation repaired.** README separators, navigation paths, and download links for Black Dossier, Nightfall Murim and Voxel Playground no longer show stray question marks.

## Download and update

Download [Naut v0.0.15 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.15/naut-v0.0.15-win-x64.zip). Extract the complete archive and run `naut.exe` alongside the supplied `runtime/` and `release-manifest.json`. For existing installations, use the signed in-app updater when available.

The updater replaces application files only. Vault content, originals, Profile data, media derivatives and user preferences remain outside the update payload.

## Notes

- No database, Vault schema, packaging format, updater signing key or original media contract changes.
- Aurora is retained as a compatibility alias to Bubbles for existing Presentation selections.
- Effect animation remains subject to system Reduced Motion and resource/visibility scheduling. Visual appearance varies with theme, Banner source and effective opacity.
