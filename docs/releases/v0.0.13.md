# Naut v0.0.13

## Highlights

- **Lighter Banner and Hover decoding.** The existing composited FFmpeg/Skia player now copies validated BGRA frame rows directly into recyclable bitmaps rather than invoking the BMP image decoder for every frame. Frame timing, orientation, still fallback, and decoder cancellation remain under the same playback authority. A focused 640×360, 120-frame in-process test measured median frame handling of 0.256 ms versus 0.650 ms through the previous BMP decode path. This measures the frame-handling kernel, not overall app speed or frame rate.
- **More efficient Backdrops and effects.** Procedural canvases reuse their native paints and correctly release transient shaders and image filters. Visual layers, effect definitions, blend modes, animation and accessibility representations are retained.
- **Fewer unnecessary UI updates.** Image and Cover/Frame presentation setters skip unchanged values; Media Cards avoid redundant favorite notifications and warning-badge recreation. Import's progress sweep reuses its clipping geometry without changing progress semantics.
- **Cleaner presentation source.** An unused Showcase framing editor was removed; the current editor and product presentation contracts remain intact.
- **Updated system guidance.** Minimum and recommended Windows specifications now distinguish product guidance from hardware actually measured. See the System requirements section in the README.

## Download and update

Download [Naut v0.0.13 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.13/naut-v0.0.13-win-x64.zip). Extract the entire ZIP to a normal application folder, preserving `naut.exe`, `release-manifest.json` and the bundled `runtime/` directory. Do not run directly from inside the ZIP.

Existing installations can use Naut's authenticated updater. The update applies to the application only; Vault content, original media, Profiles and preferences are not replaced or reimported.

## Notes

- No database schema migration, Vault format change, media derivation contract change or signed-update trust change is introduced in this release.
- The media renderer remains composited within the Uno/Skia desktop window; this release does not require a new native video presenter or hardware video-decoding capability.
- On one AMD Ryzen 3 5300U / integrated Radeon / approximately 10 GiB RAM / Windows 11 machine, isolated empty-Vault startup/idle samples showed lower CPU time in the final sampled seconds, while memory use stayed broadly similar (about 322–325 MiB working set). These short samples are not proof of universal CPU, RAM or GPU savings. Large collections, low-end hardware, broad GPU configurations, 4K media and full Import-throughput comparisons have not been benchmarked for this release.
- The revised minimum/recommended specifications are conservative guidance, not a claim that untested hardware meets a measured responsiveness threshold. See the README before deploying to a constrained device.
- The installed release date shown in About is obtained from the matching published GitHub release, with an offline AppState cache after successful retrieval; it is not embedded as an invented date.
