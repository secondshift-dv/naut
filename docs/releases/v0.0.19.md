# Naut v0.0.19

## Highlights

- Launcher, updater, and worker binaries use component versions. Previously, a new Naut release stamp inside the bundled launcher or updater forced the entire executable to download again. Future releases can reuse these files when their bytes still match.
- The replacement helper now bundles its .NET runtime in compressed form. This update downloads the newly packaged helper once. The helper can run independently during replacement and recovery.
- The updater downloads each required file identity once, even when the signed release puts the same content in multiple locations.

## Download and update

Download [Naut v0.0.19 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.19/naut-v0.0.19-win-x64.zip). For a new installation, extract the complete archive and run `naut.exe`. Existing users can update through Settings → About.

## Notes

- Download size depends on which installed files match the signed release. Older clients can continue to use the full ZIP update path.
- The portable distribution includes its .NET runtime. Updates keep the existing package layout and keep the Vault separate from the installation.
