# Naut v0.0.26

## Highlights

- Face analysis loads the packaged YuNet and SFace models on Windows installations with Unicode paths. A profiling failure can leave explicitly assigned media available while keeping its face evidence unresolved.
- Import shows elapsed time during Stage 1. Transfers can start while jobs in another lane wait for their own resource limit. Import activity keeps foreground presentation quality independent of the queue.
- Model preparation reconstructs zero-length normals and tangents from usable GLB geometry.
- Figure and Inspector view preferences retain the latest pending value while the Vault is open and retry after temporary catalog failures.

## Download and update

Download [Naut v0.0.26 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.26/naut-v0.0.26-win-x64.zip) once published. Extract the complete archive and run `naut.exe`. Existing users can update through Settings → About after publication.

## Notes

Existing Vaults remain compatible. There are no additional system requirements.
