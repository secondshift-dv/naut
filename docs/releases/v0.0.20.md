# Naut v0.0.20

## Highlights

- Naut has a new astronaut and nautilus mark on the Windows icon, startup screen, and in the app. Its circular outline stays centered as it turns during startup.
- The public README has refreshed feature artwork and clearer screenshots of the showcase.

## Download and update

Download [Naut v0.0.20 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.20/naut-v0.0.20-win-x64.zip). For a new installation, extract the complete archive and run `naut.exe`. Existing users can update through Settings → About.

## Notes

This release has the same system requirements as v0.0.19. Updates keep your Vault separate from the app installation.
