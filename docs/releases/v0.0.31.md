# Naut v0.0.31

## Highlights

- Settings opens while Vault storage metrics are calculated in the background. Vault Health shows the last available figures during refresh and reports when a new reading is unavailable.
- Profile 3D Figures check for an already validated scene outside the interface thread. A valid scene can be reused while other work occupies the import queue.
- Folder import skips opening unsupported files for readability checks and still counts them in the intake summary. Import Activity calculates the stage, progress and ETA together for each import.

## Download and update

Download [Naut v0.0.31 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.31/naut-v0.0.31-win-x64.zip). Extract the complete archive and run Naut. Existing users can update through **Settings → About**.

## Notes

This release has no additional prerequisites. Existing Vaults, import sources and Figure quality settings continue to work with the same formats.
