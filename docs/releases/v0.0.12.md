# Naut v0.0.12

## Highlights

- **Banner effects no longer freeze playback.** Selecting Film, Glitter, Shimmer, or their intensity updates the effect overlay in place instead of restarting the decoder. Video remains attached through brief Profile/Customize layout reflow.
- **Figure 3D no longer collides with Profile controls.** The shared Profile header reserves separate space for native Figure and identity/actions across built-in and optional Profile layouts. Wide layouts preserve the intended Figure-on-Banner composition; narrow layouts stack content safely.
- **Delete Profile is always last.** The destructive action appears once in the page footer after every Profile module, including when an installed pack supplies its own layout.
- **Readable Home labels without text panels.** Vault, Profile/Media/Space used statistics and section headings use neutral bold lettering with a thin dark outline on both bright and dark Backdrops. Spotlight typography remains separate.
- **Aligned, filled Profile Card badges.** Identity's rating, item count, star and heart share one centered metadata line. Rating stars and Profile favorite hearts are filled across built-in and optional Card layouts.
- **A distinct Media favorite symbol.** Favorite Media is now an outline Flame, orange when active and neutral when inactive, in Media cards and Inspector. Profile rating remains a star and Profile favorite remains a heart.
- **Release dates in Settings About.** Naut retrieves the installed version's actual GitHub publication date, saves confirmed metadata to local AppState for later offline use, and retries lookup when opening About if an earlier request failed.

## Download and update

Download [Naut v0.0.12 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.12/naut-v0.0.12-win-x64.zip). Extract the entire ZIP into a normal application folder, keeping naut.exe, release-manifest.json and the bundled runtime/ directory together. Do not run the application directly inside the ZIP.

Existing installations can update using Naut's authenticated updater. Updating the application does not modify the Vault or require a media reimport.

## Notes

There are no database schema or signed-update trust changes. Existing Vaults, settings, Profiles and installed Presentation Packs remain compatible.

The release date is the actual GitHub publication date. After successful retrieval, Naut can display the cached date offline; a first-ever lookup without Internet access cannot independently determine a GitHub publication timestamp.

A selected Profile Banner without a READY video rendition continues to use its static fallback; this update fixes playback lifecycle, not missing video asset generation.

Automated source compilation and focused isolated UI geometry and lifecycle regressions are included. Manual visual acceptance on production media, broad hardware testing and import throughput benchmarking are not claimed.
