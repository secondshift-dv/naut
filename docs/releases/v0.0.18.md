# Naut v0.0.18

## Highlights

- Recent media starts off for Profiles without a saved choice. Enable it in Customize Profile at any time.
- Each Profile remembers its own Media Grid Favorites filter when you return to the Profile or restart Naut.
- Gallery and Home fetch Cover and Banner thumbnail information together for the visible Profiles. Home retains its previous attention list if the Face Review count cannot be read.
- Catalog refreshes handle bursts without overlapping. Face matching and automatic import assignment avoid repeatedly looking up the same evidence.
- Poster cards keep long Profile titles within the artwork area.

## Download and update

Download [Naut v0.0.18 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.18/naut-v0.0.18-win-x64.zip). Extract the complete archive and run `naut.exe` alongside `runtime/` and `release-manifest.json`. Existing users can update through the signed in-app updater when available.

## Notes

- Previously saved Recent media choices continue to apply.
- This release uses the existing Vault schema and Windows x64 package layout.
