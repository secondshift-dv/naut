# Naut v0.0.22

## Highlights

- Fixed an import stall where a Windows icon (`.ico`) could leave the entire batch at Stage 1. Naut can now decode staged icons for face analysis. A face decoder failure allows the batch to continue once the required checks pass.
- For a batch already held at Stage 1 by this issue, select **Retry** after updating to resume the existing import.

## Download and update

Download [Naut v0.0.22 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.22/naut-v0.0.22-win-x64.zip). For a new installation, extract the complete archive and run `naut.exe`. Existing users can update through Settings → About.

## Notes

This release adds no system requirements or catalog migration. The update preserves the existing Vault.
