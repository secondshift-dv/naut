# Naut v0.0.33

## Highlights

- Finish Review when importing into a new Profile, including pending imports reopened after updating. Review identifies the specific item or decision that still needs attention.
- Resolve identical copies earlier during folder imports, keep removed media out of the destination Profile, and display duplicate decisions throughout large batches. Models with different recorded textures remain distinct.
- Recover face sampling for videos in Vault paths containing emoji. Skip an individual item that fails preparation so the rest of the batch can finish.

## Fixes

- Run one complete final validation per Import action and remove empty derivative directories after a cancelled batch is rolled back.
- Preserve populated Overviews when a folder's imported text is blank, and show the current and imported text before replacement. Use the same Unicode name rules when importing and editing a Profile.
- When importing the root of an existing Naut Vault, scan its Profile originals and exclude generated assets, internal work and Trash.

## Download and update

Download [Naut v0.0.33 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.33/naut-v0.0.33-win-x64.zip). Extract the complete archive and run Naut. Existing users can update through **Settings → About**.

## Notes

Naut copies imported media and preserves the original source files. To resume an import already waiting at Review, reopen it after updating.
