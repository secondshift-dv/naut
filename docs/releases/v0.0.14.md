# Naut v0.0.14

## Highlights

- **Figure 3D responds faster on warm Profile entry.** A previously validated source-detail scene can be reused from its NTFS source/Vault-identity keyed cache before acquiring a CPU-heavy job permit, launching another worker Task, or repeating NFIG validation. Cache misses and changed or unverifiable files still use canonical integrity validation, admission and fallback; LOD0 geometry, texture tiers, single Direct3D 11 viewport and native lifecycle are unchanged.
- **Less destructive Profile cache invalidation.** A Media change with concrete Media IDs now evicts only cached Profiles referencing those items through their Cover, Banner, Figure, Banner collection or initial Media page. Unfinished reads are retired conservatively. Category/Tag definition updates use the existing targeted Profile changes rather than clearing every cached Profile; global Media and ambiguous Trash changes retain full invalidation.
- **Lighter Governor at idle.** The interaction-state poll that ran every 250 milliseconds is replaced with one-shot expiry scheduling; memory-pressure measurement retains its two-second interval. Transfer contention checks avoid unnecessary locks and allocations while preserving the adaptive 0/2/4 ms strategy, dispatcher latency signal, operation admission and foreground priority.
- **Lower Import/Navigation overhead.** Transfer progress is coalesced to about 100 milliseconds, with explicit initial/final publication independent of 64 MiB durable checkpoints. Returning to an unchanged cached Surface no longer recursively re-registers the entire native-control tree; route changes and ThemeRuntime replacement still trigger registration. Responsive top-bar assignments skip unchanged values.
- **Focused cleanup.** Removed the superseded idle-tick counter/poll path and redundant per-request allocations; no second Import, Figure, cache, or presentation pipeline was added. Existing recovery, updater, optional packs and UI layout contracts remain canonical.

## Download and update

Download [Naut v0.0.14 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.14/naut-v0.0.14-win-x64.zip). Extract the complete ZIP and launch `naut.exe` with the included `runtime/` and `release-manifest.json` in their original layout. Do not run the launcher from inside the archive.

The updater applies authenticated application updates only; the Vault, managed originals, MediaAssets, Profile records and user preferences remain separate and are not replaced.

## Notes

- No changes to the Vault format, SQLite schema, persisted Presentation/pack IDs, model NFIG format, immutable originals, updater keys, signed update trust, or source media-derived contracts.
- This release changes scheduling and in-memory behavior, not video resolution, Figure quality, visual assets or Import checkpoint guarantees.
- System support tiers and the minimum/recommended hardware guidance remain as published for v0.0.13. Previous performance measurements described in the README were taken on v0.0.13; no unverified whole-application CPU, GPU or RAM improvement percentage is claimed here.
- The release publication date displayed in About is resolved from the matching public GitHub release and cached for offline use. It is not inferred or hard-coded.
