# Naut v0.0.30

## Highlights

- Fixes a crash when Naut removes a masked Spotlight or Profile Banner. Switching Home layouts, changing Spotlight and reopening a Profile keep the artwork masks defined by the installed pack.
- Vault Health names the Profile and text file in each Profile text finding, explains what needs attention and links to the affected Profile for review.

## Download and update

Download [Naut v0.0.30 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.30/naut-v0.0.30-win-x64.zip). Extract the complete archive and run Naut. Existing users can update through **Settings → About**.

## Notes

Existing presentation packs, including the official 3.0.0 collection, can be used with this release. Review or restore Profile text from the affected Profile. The Vault Health scan leaves the file and catalog text available for review.
