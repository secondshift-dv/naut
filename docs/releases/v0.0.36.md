# Naut v0.0.36

## Highlights

- Imports skip exact duplicates already owned by the chosen Profile. Identical files in a batch share one transfer, and Review displays unresolved items in pages.
- Import recovery checks the commit journal and verified files in staging and at the destination. A paused import keeps its place across a restart, and staging is preserved until cancellation rollback settles.
- JPEG XL originals stay in the Vault as `.jxl`. Naut reads their metadata, generates previews, and can play supported JPEG XL animations from the Media Inspector.
- Background import work shares a disk budget across hashing, copying and media preparation. Naut uses physical disk information on Windows to limit background contention.

## Download and update

Download [Naut v0.0.36 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.36/naut-v0.0.36-win-x64.zip). Extract the complete archive and run Naut. Existing users can update through **Settings → About**.

## Notes

This update requires no Vault schema migration. JPEG XL requires the Microsoft Visual C++ v14 Redistributable (x64).
