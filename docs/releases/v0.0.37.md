# Naut v0.0.37

## Highlights

- Import investigation uses the original admitted source-item total, including direct-transfer items, so checking duplicates no longer shrinks the denominator.
- Import results distinguish added, reused, duplicate-skipped, excluded, cancelled and failed items. Profile Add Media shows session-wide totals while preserving independent unit publication.
- Duplicate admission and commit share published-asset authority checks. Stale automatic reuse is reconsidered before commit; failed admissions are not reported as successful duplicate imports.
- Automatic transfers use a transaction-scoped representative gate, including eligible Profile Add Media units in the same session.

## Download and update

Download the [Windows x64 ZIP](https://github.com/secondshift-dv/naut/releases/download/v0.0.37/naut-v0.0.37-win-x64.zip) from GitHub Releases.

## Notes

Regular Import retains destination selection and Review. Profile Add Media retains its fixed destination and automatic publication. No Vault schema migration is introduced by these changes.
