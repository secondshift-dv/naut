# Naut v0.0.7

Naut v0.0.7 refreshes the Windows collection interface, Profile storage, recoverable deletion, media decoding and disk I/O.

## Highlights

- **More deliberate visual design.** Obsidian, Logbook and Foundry have new original Theme artwork. The Sakura, Cyberpunk and Imperial decorative Frames have been redesigned, while the existing saved presentation identifiers remain compatible.
- **Compact controls and easier reading.** Precision, Contour and Halo offer distinct, consistent control geometry. Tag labels use compact angular rectangular badges with vivid, identity-stable colors instead of rounded pastel pills; long labels retain tooltips. Updated typography and card spacing keep dense views readable.
- **Better collection layouts.** Home and Spotlight composition, Gallery cards, Profile headers, Media views and sidebars have been refined for compact windows. Focus and Editorial Spotlight keep their image and identity panels aligned across the full hero height on wide layouts and stack artwork above readable details on narrow layouts; the customization preview follows the same geometry. Spotlight strength follows the selected style, and horizontal slider visibility has been checked.
- **Reliable collection card geometry.** Gallery Wall centers small collections, Pinboard keeps the Customize Card action directly below each staggered card without excessive gaps, and Catalogue balances artwork with bordered Overview, Related, Updated and Created information. Poster cards show the Profile name before hover. Gallery virtualization finds visible cards within each masonry column rather than assuming all cards share one vertical order.
- **More coherent Profile sections.** Portrait and Dossier place Related beneath Overview rather than at the foot of the page, and Chronicle aligns its Overview and Related panels with the Profile identity column. Dossier also includes Recent Media when items exist and its visibility preference is enabled, consistent with Portrait and Chronicle; this preference controls hiding Recent Media regardless of layout.
- **More readable Workbench.** The metadata-first Media layout uses a wider preview-and-details composition with filenames, media types and secondary metadata instead of squeezing every card into the former 150-DIP envelope. Editorial and Mosaic retain their distinct arrangements.
- **Clearer interactions.** Media Favorites use a star while Profile Favorites use a heart. Import uses a simple download-arrow glyph and clearer preparation and review messages.
- **Add Media without extra steps.** From a Profile, select files and Naut imports eligible media automatically into that Profile, with durable Import Activity history, exact-duplicate reuse and evidence-based face association. Exceptional items remain actionable without blocking other media; the general Import flow still supports explicit review.
- **Safer cancellations and Vault recovery.** Cancel waits for active transfers to stop at a safe checkpoint before cleaning up; Vault Health can resume, retry, cancel or complete interrupted cleanup without sending aborted-import residue to user Trash.
- **Profile text files with explicit conflict review.** Managed NORMAL Profiles mirror Overview and Private Note into UTF-8 files. External edits require review before adoption or replacement. Folder imports can offer an Overview; source private notes are never imported. The files are plaintext, readable by anyone with filesystem access.
- **Recoverable Group Trash.** Deleting a Profile moves its exclusive Media into the same 30-day restoration group. Media still needed by another active Profile remains accessible after a verified folder relocation; deletion creates no new Unknown Profile. Restore preserves later user choices, and permanent deletion protects shared identity evidence.
- **More media inputs.** JPEG 2000 `.jp2` and `.j2k`, OGV/Theora, VOB and representative MXF inputs now use the packaged decoding paths for metadata, previews and analysis. Video inputs also receive Thumbnail and Hover assets. Corrupt inputs fail without changing their originals; support remains dependent on the contained codec.
- **Fewer HDD checkpoints.** Transfers retain one staged copy, incremental SHA-256, durable Resume and safe Cancel while using a 64 MiB checkpoint interval. Five interleaved runs per configuration on the test HDD measured a 27.26% median transfer-handler gain over 16 MiB checkpoints; this is a component benchmark, not an overall Import or UI speed claim.
- **Reuse verified Figure assets.** On supported NTFS volumes, a durable validation receipt can prove a prepared NFIG unchanged without hashing all its bytes again. Changed or uncertain identity/journal evidence requires full validation, and Deep Health always validates fully. Noncritical MediaAsset maintenance runs after mandatory startup recovery.
- **Three meaningful Media layouts.** Mosaic, asymmetric Editorial and metadata-first Workbench replace the old Reel choice, retaining saved-layout and Presentation Pack compatibility. Profile Media now uses its owning page scroll and bounded pagination.
- **Less clutter in Home and Inspector.** Built-in Home layouts avoid a redundant Favorites rail, Spotlight framing is refined, and Media Inspector presents Info and People without an extra EXIF tab. Metadata extraction and existing library data remain intact.
- **Clearer media capabilities.** Supported-format behavior and failure explanations are more accurate; video thumbnails and hover derivatives are prepared for readable previews. This update does not claim universal codec or decoder support.
- **Independent Vault identity.** Each Vault can have its own name and custom icon through Settings → Vault. Choose a PNG, JPEG or WebP image up to 8 MB, or restore the default icon for that Vault alone. The icon is stored inside its Vault, so switching Vaults restores each one's identity, and renaming, moving or reopening a Vault preserves its icon.
- **Transparent Profile Figures.** Live 3D Figures blend with the selected Profile Backdrop instead of showing a baked opaque background; the thumbnail remains available as a fallback.
- **Shorter wording in eight languages.** Appearance, Presentation, Import and review copy has been revised, with localization keys and formatting placeholders verified.

## Download and update

[Download Naut v0.0.7 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.7/naut-v0.0.7-win-x64.zip).

New users can extract the full ZIP and run `naut.exe`. Existing users can use Naut's supported updater or replace the portable application files with the complete ZIP. Keep the Vault outside the application folder.

## Notes

- This version is distributed through the official `secondshift-dv/naut` release channel. The linked package is valid once GitHub Release v0.0.7 is published.
- The Win32 Uno 6.6.184 UI Automation structure-change ABI is corrected during packaging with pinned upstream and patched assembly hashes. The packaged runtime retains accessibility support and passes native FigureHost reparent, layout, GPU and shutdown checks, as well as an isolated Naut startup and clean shutdown.
- **Verification limits:** earlier development checks exercised data, codec, recovery, receipts and representative native surfaces including Profile, Gallery, Home, Import, Settings and Vault Health on isolated data. Final release verification covers source compilation and deterministic package/update integrity, not a fresh exhaustive native visual-acceptance matrix or a production Vault. Extended DPI 125–200%, input P95 under HDD contention, 1k/10k live UI stress and the exhaustive failure matrix were not independently measured.
- Existing saved Presentation selections and installed Presentation Packs retain their identifiers. Recognized Catalog Schema v1 Vaults upgrade atomically to v2 without resetting user rows. Older v1 binaries reject the upgraded catalog; use a pre-upgrade Vault backup if downgrading. The application updater retains its signed-manifest, integrity-check and rollback protections.
- Language checks cover key completeness and formatting placeholders in eight languages; they are not independent native-language certification. The latest Gallery, Profile and Media layout refinements have not been subjected to a fresh exhaustive 27-combination native visual and interaction matrix.
- No additional operating-system prerequisite is introduced. Figure receipt reuse requires trustworthy NTFS file identity and USN journal evidence; unavailable evidence falls back to full validation. RAW/DNG and additional 3D formats are not introduced.
