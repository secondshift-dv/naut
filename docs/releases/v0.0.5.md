# Naut v0.0.5

A focused update to keep Naut responsive while downloading and preparing application updates.

## Highlights

- **Update progress no longer rebuilds Settings.** Status, available version, and error messages update in place, avoiding repeated reconstruction of the About page.
- **Bounded progress updates.** Rapid download notifications are limited and a slow interface keeps only the latest pending state, preventing an accumulating queue of UI work.
- **Cleaner handoff to the updater.** New user writes are closed at the update handoff, while existing work still follows the controlled shutdown and recovery path.

## Download and update

[Download Naut v0.0.5 for Windows x64](https://github.com/secondshift-dv/naut/releases/download/v0.0.5/naut-v0.0.5-win-x64.zip).

New users: extract the ZIP and run `naut.exe`.

Existing users: update through Naut. If your older version freezes during an update, close it and manually replace the application files using this ZIP. Keep your Vault separate from the application folder. See [getting started](https://github.com/secondshift-dv/naut/blob/v0.0.5/docs/getting-started.md).

## Notes

- This fix takes effect after v0.0.5 is installed. An older running version still uses its previous update interface.
- Signed manifests, file hashes, staging, backups, rollback, and Vault isolation remain enforced.
- The updater continues to download changed files in full; this release does not introduce binary delta downloads.
- FBX, OBJ, STL, and 3MF conversion still requires Microsoft Visual C++ v14 Redistributable x64. Figures remain static models.
