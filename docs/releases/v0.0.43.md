# Naut v0.0.43

## Highlights

- Contract 4 Media Layout collections can align each Grid or Editorial row at the start, center or end, including the final incomplete row.
- Live Overlay Media Layouts can hide the decorative hearts and redundant heart indicator while retaining the metadata scrim, footer, and functional Favorite button.

## Download and update

The [Windows x64 ZIP](https://github.com/secondshift-dv/naut/releases/download/v0.0.43/naut-v0.0.43-win-x64.zip) is the release asset. Extract the complete archive and launch naut.exe, or check for the signed update in Settings.

## Notes

Presentation Contract 4, manifest schema 1 and Catalog Schema 4 remain unchanged. Existing packs retain their previous alignment and decorative hearts when the new options are omitted. No Vault migration is required from v0.0.42. The new optional renderer fields require Naut v0.0.43 to take effect. Users upgrading from a pre-schema-4 release should back up the complete Vault before opening it.
