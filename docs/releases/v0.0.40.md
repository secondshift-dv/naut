# Naut v0.0.40

## Highlights

- Contract 4 Home layouts can use a shared aspect-preserving immersive stage, marquee Spotlight, favorite-only cover rails, HUD statistics and overlay navigation.
- Modular Profile layouts support local paper palettes, independently placed tags and profile tools, flexible Figure height and wide Banner compositions.
- Gallery layouts can use fixed-aspect slots, viewport artwork and decorative Customize Card controls while keeping each Profile's own Card and native actions.
- Profile Cards support independent resting and Banner-hover canvases, pack-owned artwork layers and native rating stars. Missing Banner media retains the resting composition.
- Compatible packs can style portrait media with a live metadata overlay, a Favorite heart and filename footer, add artwork to the Import dropzone, and present the Media Inspector in a phone-style shell. Control skins can add subtle breadcrumb stripes.

## Download and update

Download the [Windows x64 ZIP](https://github.com/secondshift-dv/naut/releases/download/v0.0.40/naut-v0.0.40-win-x64.zip) from GitHub Releases. New users extract the complete archive and launch naut.exe. Existing users can check for the signed update from Settings.

## Notes

Presentation Contract 4 and Catalog Schema 4 remain unchanged. New optional presentation fields require a renderer that supports them; existing layouts retain their default behavior when omitted. No additional system requirements apply. Application replacement remains separate from Vault storage; users upgrading from a pre-schema-4 release should back up the complete Vault before opening it. No new performance benchmark is claimed.
