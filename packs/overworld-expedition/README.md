# Voxel Playground 4.0.0

Source requires Presentation Contract 4. Published 3.0.0 downloads require Naut v0.0.29 or later (Contract 3).

Creative Hub puts the projects you can resume first. Below, World Portal sits beside the activity and statistics panels, with a stacked arrangement in a narrow window.

The stepped portal puts its caption before the artwork, with the image and pagination able to reflow separately on narrow Home.

The Figure is the main work surface on wide layouts, with the project identity and a compact Banner alongside it. Media follows as a shelf of builds.

World Keepsake retains its 2.15:1 aspect, framed Cover and centered name over an ambient Banner. An available clip plays on hover.

Install from **Settings → Presentation → Packs / Advanced → Install from file**.
Select **Replace** when upgrading and keep saved choices by using the same pack ID.
Select **Creative Hub** and **World Portal** in Home Customize, then save.
Select **Builder's Workshop** under Profile Customize. Choose a Cover Frame and Backdrop there, or a Card in Customize Card, then save.
Both Backdrops can be selected and saved independently in Home and Profile Customize.
Choose available Themes, Typography and Controls in **Settings → Appearance**.
