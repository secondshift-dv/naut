# Black Dossier 3.0.0

Requires Naut v0.0.29 or later (Presentation Contract 3).

Attention and imports lead the Operations Desk. The separate reconnaissance image, subject and pagination stay grouped on the right on wide layouts.

An angled surveillance crop holds the artwork. The subject and controls occupy their own briefing column, or move below the artwork in a narrow window.

The dossier puts identity, overview and related records beside a clipped Banner and an independent Figure. Media and review form the evidence section below.

Dual Identity keeps the framed Cover separate from Banner. A Cover-only Profile leaves the unused Banner region blank. A ready Banner clip plays on hover.

Install from **Settings → Presentation → Packs / Advanced → Install from file**.
Select **Replace** when upgrading and keep saved choices by using the same pack ID.
Select **Operations Desk** and **Opening Brief** in Home Customize, then save.
Select **Subject Dossier** under Profile Customize. Choose a Cover Frame and Backdrop there, or a Card in Customize Card, then save.
Both Backdrops can be selected and saved independently in Home and Profile Customize.
Choose available Themes, Typography and Controls in **Settings → Appearance**.
