# Official optional presentation packs

The 4.0.0 source collection requires Presentation Contract 4. Published 3.0.0 downloads require **Naut v0.0.29 or later** (Presentation Contract 3).
Use the 2.1.0 archive links below for older Naut versions that support the Contract 1 collection.

In **Settings → Presentation → Packs / Advanced**, install the downloaded file.
Choose **Replace** when updating a pack with the same ID. In Home and Profile Customize,
choose and save layouts, Backdrops and Effects independently. Pick Cover Frames in Profile
Customize and Card layouts in Customize Card. Themes, Typography and Controls are in Appearance. Global Presets apply a coordinated selection.

## Black Dossier - 4.0.0 source

![Black Dossier native Home, Gallery, Profile and Frame previews](showcase/black-dossier.png)
