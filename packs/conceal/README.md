# Conceal 2.1.0

Tracing Index leads with shortcuts, statistics and activity. Under Glass omits Cover and Overview. Veiled Identity retains conceal.card and the 2.15:1 aspect. Hover reveals clear art and details. The retired conceal.wide-keepsake selection falls back; choose the wide World Keepsake in Voxel Playground for a framed alternative.

| Component | Name |
| --- | --- |
| Card | Veiled Identity |
| Backdrop | Tracing Sheets |
| Backdrop | Smoked Glass |
| Frame | Folded Tracing |
| Frame | Tracing Ring |
| Theme | Tracing Paper |
| Home | Tracing Index |
| Spotlight | Under Glass |
| Profile | Tracing Folio |
| Media | Tracing Sheets Grid |

Install in **Settings → Presentation → Packs / Advanced → Install from file**.
For upgrades, select **Replace** when prompted. Installation adds choices. In
Home Customize, select **Tracing Index** and **Under Glass**, then save.
Both **Tracing Sheets** and **Smoked Glass** are available in Home and Profile Customize. Save
each surface separately. Choose a frame in Profile Customize and a Card in
Customize Card. Themes, typography and controls are in Settings → Appearance.
