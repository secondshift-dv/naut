# Conceal 3.0.0

Requires Naut v0.0.29 or later (Presentation Contract 3).

Tracing Index presents a short summary and activity first. The artwork is secondary and the Spotlight omits Cover and Overview.

An aperture cut into a folded pane exposes a small artwork strip beside a compact identity. Identity, artwork and page controls have independent placement.

The folio puts identity above a narrow Banner and overview. The media index follows, with Figure and review farther down the page.

Veiled Identity is the sole Card and retains its 2.15:1 aspect. It blurs Cover and Banner and hides identity details at rest. Hover reveals clear artwork and details. The retired Wide Keepsake resolves to the Naut fallback. For a framed wide card, install Voxel Playground and choose World Keepsake.

Install from **Settings → Presentation → Packs / Advanced → Install from file**.
Select **Replace** when upgrading and keep saved choices by using the same pack ID.
Select **Tracing Index** and **Under Glass** in Home Customize, then save.
Select **Tracing Folio** under Profile Customize. Choose a Cover Frame and Backdrop there, or a Card in Customize Card, then save.
Both Backdrops can be selected and saved independently in Home and Profile Customize.
Choose available Themes, Typography and Controls in **Settings → Appearance**.
