Naut adalah **pengelola koleksi media local-first untuk Windows**. Gambar, video, dan Figure 3D interaktif opsional diorganisasi di sekitar Profile dalam Vault portabel yang tetap berada di bawah kendali pengguna.

## Yang dapat dilakukan Naut

- Profile dengan Cover, Banner, kategori, tag, rating, catatan pribadi, dan hubungan antar-Profile.
- Import dengan **menyalin** media ke Vault; file asli tetap di tempat asal.
- Kustomisasi Home, Gallery, Card, layout Profile, Frame, Backdrop, Effect, dan Theme tanpa mengubah media asli.
- Video hover/banner yang dipersiapkan secara terkontrol.
- Figure 3D interaktif berbasis Direct3D 11 sebagai fitur opsional.
- Aplikasi portabel yang terpisah dari Vault sehingga update aplikasi tidak mengganti koleksi.

## Mulai cepat

1. Download **Naut v0.0.1** dari [GitHub Releases](https://github.com/secondshift-dv/naut/releases/tag/v0.0.1).
2. Extract seluruh ZIP.
3. Jalankan `naut.exe`.
4. Pilih **lokasi penyimpanan** Vault.
5. Import media atau tambahkan media dari sebuah Profile.

Lihat [Dokumentasi Naut](docs/README.md) dan [System Requirements](docs/system-requirements.md). Minimum: Windows 10/11 x64, CPU 2-core x86-64, RAM 8 GB, grafis terintegrasi, layar 1280×720, dan 1.5 GB ruang bebas untuk aplikasi/update. Recommended: CPU modern 4+ core, RAM 16 GB, layar 1080p, serta GPU Direct3D 11 yang lebih kuat untuk Figure.

Naut-owned source bersifat **Source Available** di bawah PolyForm Shield 1.0.0. Binary resmi dan metadata update bertanda tangan hanya diterbitkan melalui **GitHub Releases** resmi `secondshift-dv/naut`.
